**Major finding (from reading installed SDK source and docstrings, zero new API calls):** The official OpenAI Python SDK's own docstring for `PromptCacheOptions` (in `.venv/Lib/site-packages/openai/types/chat/completion_create_params.py` and the matching `responses` module) states explicitly:

> "By default, OpenAI automatically chooses one implicit cache breakpoint. ... **Set `mode` to `explicit` to disable the implicit breakpoint.**"

This means `mode="explicit"` does not request a *better* or *guaranteed* form of caching — without also manually inserting `prompt_cache_breakpoint` markers into message content (via PydanticAI's `CachePoint`, which this project never used), **explicit mode turns the only caching mechanism OFF**.
